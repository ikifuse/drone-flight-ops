# ADR-0015: 記録・保存先から設計し、差分監査後に依存実装へ進む

- **作成日**: 2026-09-18
- **ステータス**: 提案中（Proposed）
- **設計ベースライン**: 99.2 §0・§1の到達点はCURRENT-ACCEPTED。ADR Acceptedとは別軸であり、今回ADR承認へ昇格させない。
- **関係性**: Clarifies [ADR-0007](ADR-0007-normalized-masters-and-business-reporting.md)の正規化・拡張性と、人間向け記録を先に確かめる設計順序との関係。Supersedesなし。具体的なシート構造・帳票レイアウトの置換は含まない。
- **判断の由来**: 99.2 §0・§1およびオーナーの再移植指示。AIは根拠の配置と記録を担当。
- **関連要件**: [00_goal §1.1](../00_goal.md#11-記入支援を中心に置くまでの因果)、[23 開始ゲート](../architecture/23_implementation-roadmap.md#12-保存出力を確かめてから依存実装へ進むゲート)、[出典と対照](../migration/99-2-step-1-causal-audit.md)。

## 1. 背景と課題（Context）

`0211a9a`の実装計画はC1で永続化・Domain、C8で帳票生成を構築する段階構成だった。`5d51315`のADR-0007は、特定個人・機材・印刷枠に構造が縛られる問題から、正規化と複数機材・業務利用への拡張を採用した。その理由は保持する。

99.2 §1は、実装を進められない期間にも設計検討を継続する必要と、保存・出力構造を未確定のまま実装するとモデル、保存、同期、帳票、テスト、移行へ連鎖修正が生じる問題を記録した。実装順序だけでは、その前に何を確かめるべきかが明確にならない。

## 2. 検討した選択肢（Options Considered）

99.2 §0・§1が対比している進め方を整理する。

- **保存・出力未確定のまま依存実装を進める**: 技術用のテーブル・内部構造を先に決めて人の運用を合わせる進め方を含む。同節が問題として挙げる方法。
- **必要な記録・出力・保存先を見える化してから依存実装へ進む**: 実Driveで確認し、論点単位で正式Docsへ移植、差分監査を行う。同節の現在到達点。

## 3. 決定内容（Decision）

後者を現在の設計ベースラインとして記録する。具体的な着手条件・更新の流れの記録項目は[23 §1.2](../architecture/23_implementation-roadmap.md#12-保存出力を確かめてから依存実装へ進むゲート)だけを詳細正本とする。実物・状態・質問の扱いは[設計証拠規約](../guidelines/03_design-evidence-and-causality.md)を参照する。

## 4. 採用理由と他案の却下理由（Rationale）

利用者が必要な記録へ迷わず記入でき、正しい保存先へ自動反映されることが目的である。出力先が未確定の状態をコードで先に固定すると、後の確認で運用と食い違い、連鎖修正とAI実装・レビュー・再修正の負担を増やすため採らない。実物確認は利用者が不足や矛盾を発見するために必要だが、試作品が存在するだけで最終仕様とする方法も採らない。

正規化の目的である保守性・拡張性を捨てる判断ではない。人が使う帳票を一枚で成立させる前提と、内部モジュールの責任分離を別の対象として扱う。具体的な分割が必要な場合の説明・合意の境界は設計証拠規約を参照する。

## 5. メリット（Pros）

入力、保存、帳票・台帳更新の関係を実装前に確かめられる。技術構造だけを先に固定することによる手戻りを減らし、将来の保守・検証時にも判断の理由を辿れる。

## 6. デメリット・トレードオフ（Cons / Trade-offs）

依存部分の実装前に、保存先・出力単位・権限・運用構造の確認と正式Docsの差分監査が必要になる。試作は確認の助けになるが採用の自動証明にはならず、未確定事項を埋めずに管理する必要がある。これは99.2の進め方から生じる作業上の負担の整理であり、新しい業務仕様ではない。

## 7. 将来この決定を見直す条件（Re-evaluation Triggers）

後続の設計検討で目的・運用・必要な記録や出力が変わった場合、本判断も変更可能とする。新しい根拠と変更理由を同じ因果に残す。CURRENT-ACCEPTEDを永久確定の意味には用いない。未確定の個別保存先が存在することは、原則自体をPENDINGへ戻す理由にはならない。
