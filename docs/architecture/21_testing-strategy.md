## 1. テストピラミッドと検証境界

「実装後にまとめてテストする」のではなく、各モジュール実装と同時に継続的自動テストを実施します。

```text
       ▲
      / \        [E2E・実機テスト] (iPhone 13 / Pixel 6a実機検証)
     /   \       - 現場片手タップ操作、PWAホーム追加、オフライン起動
    /─────\
   /       \     [統合テスト (Integration)] (Vitest / Playwright)
  /         \    - 同期キュー、Dexie.js永続化、DIPS Mock通信、手動修正競合
 /───────────\
/             \  [単体テスト (Unit)] (Vitest) - 最も厚く高速に実行
                 - 運航状態マシン、バッテリーサイクル計算、機体累計時間、
                   FlightAreaジオメトリ計算、法令様式マッピング
```

---

## 2. 主要テスト領域と検証項目

### 2.1 単体テスト（Unit Tests）
- **運航状態マシン**: 不正な遷移（点検前に離陸、飛行中にBAT交換等）が確実に拒否されること。
- **計算エンジン**: ミリ秒打刻からの飛行時間（分・秒）算出、累積時間の丸め処理が正確であること。
- **バッテリー生涯追跡**: サイクル数の加算、充放電深度の追跡ロジック。
- **FlightArea計算**: 円形バッファおよび多角形ポリゴンの頂点座標バリデーション。

### 2.2 統合テスト（Integration Tests）
- **オフライン・同期キュー**: 通信切断状態でジョブが安全にキューイングされ、オンライン復帰時に順次送信されること。
- **DIPS Adapter Mock**: 認可コードフロー、トークンリフレッシュ、受付番号受領、4xx/5xxエラーハンドリング。
- **スプレッドシート競合解決**: 手動修正フラグがある場合に、端末側の過去データで上書きされないことの検証。

### 2.3 実機検証（iPhone 13 & Pixel 6a）
- **iPhone 13 (iOS Safari / WebKit)**:
  - 「ホーム画面に追加」によるフルスクリーン起動。
  - `navigator.storage.persist()` の挙動と永続化ステータス表示。
  - 画面ロック復帰時のタイマー計測の継続。
  - 屋外高コントラスト表示の視認性。
- **Pixel 6a (Android Chrome)**:
  - PWAインストール、オフライン起動。
  - GPS現在地測位の精度確認。
  - バックグラウンド切替時のアプリ復帰。
