## 1. 地図・空域データのレイヤー構造

本システムでは、描画・計算・判定の独立性を担保するため、地図および空域規制データを以下の5つの独立レイヤーとして階層管理します。

```text
┌─────────────────────────────────────────────────────────────┐
│ [レイヤー5: 飛行範囲レイヤー (FlightArea)]                  │
│  - パイロットが描画した円（中心＋半径）または多角形ポリゴン│
├─────────────────────────────────────────────────────────────┤
│ [レイヤー4: 周辺飛行計画レイヤー (Surrounding Plans)]       │
│  - DIPSから取得した他機の飛行計画表示                       │
├─────────────────────────────────────────────────────────────┤
│ [レイヤー3: 航空法規制空域レイヤー (Regulated Airspace)]    │
│  - 空港等周辺空域、進入表面、緊急用務空域                   │
├─────────────────────────────────────────────────────────────┤
│ [レイヤー2: 人口集中地区レイヤー (DID)]                     │
│  - 国勢調査DID境界ポリゴン                                  │
├─────────────────────────────────────────────────────────────┤
│ [レイヤー1: 地図背景タイル (Base Map Tiles)]                │
│  - 国土地理院タイル（標準地図 / 淡色地図 / 航空写真）      │
└─────────────────────────────────────────────────────────────┘
```

## 2. 飛行範囲（FlightArea）の内部標準データモデル

パイロットが現場で直感的に操作でき、かつDIPS通報仕様にも適合するハイブリッド表現を採用します。

### 2.1 データ定義
```typescript
export interface FlightArea {
  flight_area_id: string;      // UUID v4
  name: string;                // 現場名（例: "〇〇海岸フライト"）
  shape_type: 'circle' | 'polygon';
  
  // 円形指定時
  center?: {
    latitude: number;          // 10進（例: 35.6895）
    longitude: number;         // 10進（例: 139.6917）
    radius_meters: number;     // 半径（m）
  };

  // 多角形ポリゴン指定時
  polygon_coordinates?: [number, number][]; // [ [lng, lat], [lng, lat], ... ]

  // 共通空域属性
  max_altitude_agl_meters: number; // 対地高度（上限150m等）
  geojson: GeoJSON.Feature;        // 標準GeoJSON表現（自動生成保持）
  
  created_at: string;
  updated_at: string;
}
```

### 2.2 操作機能
- **円描画モード**: 地図上をロングタップして中心点を決め、スライダーまたはドラッグで半径（m）を直感指定。
- **ポリゴン描画モード**: 頂点をタップして順次追加。ピンチ操作で微調整。
- **過去範囲の再利用・複製**: 過去の飛行実績からワンタップで同一エリアを呼び出し、再計画へ適用。

## 3. 空域データソースの選定・更新・規約整理

| レイヤー | データ提供元 | 利用規約・費用 | 更新頻度 | オフラインキャッシュ設計 |
|---|---|---|---|---|
| **国土地理院タイル** | 国土交通省 国土地理院 | 国土地理院利用規約に準拠（無償利用可、出典表示必須） | 定期更新 | 現場予定地点のズームレベル10〜16を事前ロード・キャッシュ |
| **DID（人口集中地区）** | e-Stat / 国土数値情報 | オープンデータ（CC BY 4.0等、無償） | 5年ごと（国勢調査準拠） | GeoJSONベクトルとして事前バンドル（軽量化圧縮） |
| **空港等周辺空域** | 国交省航空局オープンデータ / G空間情報センター | 無償オープンデータ規約 | 航空路誌（AIP）改訂時 | GeoJSONとしてアプリ内キャッシュ、最終更新日を表示 |
| **緊急用務空域** | 国交省航空局告示 | 都度告示 | 災害・事故発生時 | 通信接続時のみ動的取得（オフライン時は「未確認」と明示） |

> [!IMPORTANT]
> **空域判定の責任境界**:
> アプリ上で規制空域に重なっていないと表示された場合でも、「アプリによる表示は参考情報であり、最終的な飛行可否・法規遵守は操縦者の自己責任である」旨の免責文言およびデータ最終更新日を明記します。
