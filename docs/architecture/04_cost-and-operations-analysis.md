## 1. 前提条件（利用規模）

- **利用形態**: オーナー個人によるドローン運航管理（1人利用、私用・個人業務）。
- **データ規模**: 年間数十〜数百フライト、機体数2〜数機、バッテリー数7〜十数本程度（データ容量としては数MB〜数十MB以内）。
- **基本方針**: 有料SaaSを契約せず、**「現行の無料枠やオープンデータを最大限活用して追加コストを極小化」**し、個人で無理なく保守できること。

## 3. 各項目のコスト・運用分析

### 3.1 アプリストア公開とApple Developer費用の実際
- **iOSアプリを実機で動かす場合の制約**:
  - 無料のApple IDを用いてもMac（Xcode）からiPhone実機へアプリを転送可能ですが、**「有効期限が7日間」「最大3アプリまで」**という制限があり、毎週署名更新が必要となるため現場運用には適しません。
  - 期限なしで快適に利用、またはTestFlightで配布するには、**Apple Developer Program（年額99米ドル＋税、日本円で約13,000円前後・為替で変動）の有料契約が毎年必要**となります。
- **PWA（Progressive Web App）によるコストと手間の回避**:
  - Safariの「ホーム画面に追加」を行うことで、有料開発者登録やAppleの審査を一切介さず、iPhoneのホーム画面からフルスクリーンで起動できます。

### 3.2 地図・空域データ費用の実態
- **国土地理院タイル**:
  - 標準地図、淡色地図、航空写真タイルは、国土地理院の利用規約に基づき無償で利用可能です。オープンソースの **MapLibre GL JS / Leaflet** を用いることで、商用APIのような従量課金を回避できます。
- **留意事項（空域データ）**:
  - 地図画像タイルが無償であることと、ドローン規制空域（DID、空港周辺、進入表面、緊急用務空域等）の完全なデータ取得は別問題です。
  - 国交省オープンデータ（DID等）の活用や、オフライン時のキャッシュ容量制限、最新規制情報の更新性については、B2以降でデータソースごとに規約と更新頻度を精査する必要があります。

### 3.3 バックエンド・クラウド費用
- **Cloudflare Workers / Pages**:
  - 現行仕様（2026年9月確認）では、無料プランで **「1日100,000リクエスト」**、**「CPU時間 10ms / HTTPリクエスト」** まで無償提供されています。
  - 個人1名によるドローン運航記録の利用規模（1日数十〜数百回程度）であればリクエスト数上限には十分収まる見込みですが、将来DIPS認証処理やレスポンス変換を実装した際にCPU時間10ms以内で安定動作するかは検証が必要です。
  - また、「将来にわたる永久無料」を保証するものではなく、ベンダーの利用規約や料金改定のリスクは常に存在します。

### 3.4 特定クラウド依存（ベンダーロックイン）の回避
- 特定のクラウドサービスが有料化・サービス終了した場合に備え、最終的なデータ原本やエクスポート形式を「Googleスプレッドシート」や「ローカルPDF/CSV」として独立保持できるアーキテクチャとすることで、インフラ移行の自由度を確保します。
