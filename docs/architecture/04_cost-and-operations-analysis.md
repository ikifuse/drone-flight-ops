## 1. 前提条件（利用規模）

- **利用形態**: オーナー個人によるドローン運航管理（1人利用、私用・個人業務）。
- **データ規模**: 年間数十〜数百フライト、機体数2〜数機、バッテリー数7〜十数本程度（データ容量としては数MB〜数十MB以内）。
- **基本方針**: 有料SaaS（月額数千円〜数万円）を一切契約せず、**「可能な限り月額0円・永久無料枠」**で安定運用し、個人で無理なく保守できること。

## 3. 各項目のコスト・運用分析

### 3.1 アプリストア公開とApple Developer費用の真実
- **iOSアプリの最大の壁**:
  - iPhoneでネイティブアプリ（FlutterやSwift）を動かすには、App Storeへ公開するか、TestFlight経由で配布する必要があります。
  - そのためには **Apple Developer Program（年間 12,980円 税込）の有料契約が毎年必須** となります。更新を怠るとアプリが起動しなくなります。
  - また、TestFlightは「90日間の有効期限」があり、3ヶ月ごとにMacを開いて再ビルド・再アップロードしなければならないという過大な運用負担が発生します。
- **PWA（Progressive Web App）による劇的なコスト削減**:
  - Safariの「共有」ボタンから「ホーム画面に追加」するだけで、iPhoneのホーム画面にアプリアイコンが作成され、全画面で起動します。
  - **Apple Developer登録は完全不要（0円）**、有効期限なし、Macでのビルド作業も不要です。

### 3.2 地図タイルAPI費用
- Google Maps Platform や Mapbox などの民間地図APIは、月間リクエスト上限を超えると急激な従量課金（クレジットカード引き落とし）が発生するリスクがあります。
- 一方、**「国土地理院ベクトルタイル / 標準地図・淡色地図・写真タイル」** は、日本の国土交通省が提供する公的オープンデータであり、**商用・非商用問わず完全無料**で利用できます。ドローン飛行に必須の「DID（人口集中地区）データ」も国交省から無償提供されています。
- これらをオープンソースの **MapLibre GL JS / Leaflet** で表示することで、地図費用を永久に0円に抑えられます。

### 3.3 バックエンド・クラウド費用
- **Cloudflare Workers / Pages**:
  - 無料プランで **「1日10万リクエスト」** まで完全に無料。
  - 個人が1日にドローンを飛ばして通報・記録する通信は数十〜数百回程度であり、無料枠の0.5%も消費しません。
  - クレジットカード登録なしで利用できるため、予期せぬ請求事故（パケ死・課金爆発）が物理的に発生しません。

### 3.4 将来のサービス終了・ベンダーロックインリスク
- 特定の独自クラウドDBやプロプライエタリなSaaSにデータを依存すると、そのサービスが終了した際に過去の飛行日誌を取り出せなくなる危険があります。
- **本システムでは、最終台帳を「Googleスプレッドシート」および「ローカルCSV/PDF出力」に逃がす設計**とすることで、特定のクラウドインフラに依存しない永久保存性を確保します。
